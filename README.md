# DateFruit Classification System

A Deep Learning project that classifies different types of date fruits using an Artificial Neural Network (ANN) built with PyTorch.

## Project Overview
This project focuses on multi-class classification using Deep Learning techniques. The model learns patterns from the Date Fruit dataset and predicts the correct category of date fruits based on their features.

## Dataset
Dataset: Date Fruit Dataset

Features include:
- Area
- Perimeter
- Major Axis Length
- Minor Axis Length
- Eccentricity
- Convex Area
- Shape-related attributes

Target:
- Different Date Fruit Classes
